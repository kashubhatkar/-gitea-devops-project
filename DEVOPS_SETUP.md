# Gitea Local Setup

## What I did

- Cloned the Gitea repository.
- Studied the project documentation and repository structure.
- Set up the required Go and frontend dependencies.
- Built Gitea locally without Docker.
- Ran and verified Gitea on the local system.
- Resolved build and environment issues during setup.

## Learning

I learned about the structure of a large open-source Go project, dependency setup, building from source, Git branches, GitHub repositories, and Pull Requests.
